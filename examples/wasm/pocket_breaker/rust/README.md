PocketBreaker in Rust
=====================

Move the paddle with left and right. Press A to launch the ball after a miss or
after clearing the wall.

`main.rs` contains the game. `vmu.rs` provides the small safe screen and input
API it uses. `waterbear_vmu.rs` is generated by `waterbear wasm header` and
contains the raw unsafe declarations.

Install the `wasm32-unknown-unknown` Rust target and build Waterbear in the
repository root, then run:

    make

The resulting `pocket_breaker.vms` is written to this directory. Set
`WATERBEAR` or `CARGO` on the `make` command line to use different tools.
