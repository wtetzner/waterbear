PocketBreaker in C
==================

Move the paddle with left and right. Press A to launch the ball after a miss or
after clearing the wall.

`main.c` contains the game. `vmu.h` provides the small screen and input API it
uses. `waterbear_vmu.h` is generated by `waterbear wasm header` and contains the
raw VMU declarations.

Install an LLVM Clang with the WebAssembly backend, build Waterbear in the
repository root, then run:

    make

On macOS, `brew install llvm lld` installs the required compiler and linker.
The Makefile automatically uses them from the standard Apple Silicon or Intel
Homebrew paths.

The resulting `pocket_breaker.vms` is written to this directory. Set
`WATERBEAR`, `CC`, or `WASM_LD` on the `make` command line to use different
tools.
